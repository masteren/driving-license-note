## 📊 カテゴリ別の弱点

| カテゴリ | 該当問題 | 問題数 |
|---------|---------|:------:|
| 車が通行してはいけない場所 | Q8, Q9 | 2 |
| 交差点の通り方２ | Q10, Q11 | 2 |
| 標識・標示の種類と意味 | Q4, Q5 | 2 |
| 車両・免許の基礎知識 | Q1, Q2, Q3 | 3 |
| 手信号 / 速度 / 行き違い / 追い越し | Q6, Q7, Q12, Q13 | 4 |

> 「通行禁止の場所」と「交差点の通り方」で繰り返し失点しているため、本免試験前はこの 2 分野を優先的に見直す。

## 💡 よく引っかかるパターン

<table>
<tr><th align="left">パターン</th><th align="left">内容</th><th align="left">該当</th></tr>
<tr>
  <td>絶対禁止に見える罠</td>
  <td>「〜してはならない」と書かれていても、<b>例外が用意されている</b>ことがある</td>
  <td>Q8（軌道敷）</td>
</tr>
<tr>
  <td>条件付きに見える罠</td>
  <td>「〜のときに限り可能」と書かれていても、実際は<b>条件なく禁止</b>のことがある</td>
  <td>Q9（安全地帯）</td>
</tr>
<tr>
  <td>標識と標示の混同</td>
  <td><b>標識＝立て看板</b>／<b>標示＝路面の線</b>。問われている対象を読み違えない</td>
  <td>Q4, Q5</td>
</tr>
<tr>
  <td>独特な言い回し</td>

  <td>Q6</td>
</tr>
<tr>
  <td>似た用語の対比</td>
  <td>進路を<b>変える</b>＝追い越し／<b>変えない</b>＝追い抜き</td>
  <td>Q13</td>
</tr>

## 📖 このノートの使い方

1. 各 Day のノートで **問題文 → 自分で正誤を判断 → 解説を確認** の順に進める
2. 図解画像で、標識・標示・状況のイメージを合わせて覚える
3. 上の「よく引っかかるパターン」を試験直前に読み返す
